The science

Identical relevance grades cannot certify retrieval-augmented AI answers. An aggregate score, including the same grade on two retrieved passages, does not certify that the answer a person would act on is unchanged.

Method, in plain language

Professor NooR (King Abdulaziz University) is submitting this argument as a manuscript. This page describes that manuscript as under review. A preprint is forthcoming.

Matched items

Both versions answer the same questions, with the same case identifiers. A comparison that uses different questions for each version cannot say which answers moved.

Repeated runs

Each version is run more than once on those matched items. One run cannot separate an update from an answer that would have changed on its own.

Execution floor

The execution floor is the re-execution noise baseline: how often the same version disagrees with itself. Answer changes have to be read against that floor. A change that sits inside the noise is not evidence about the update.

Exact test

The manuscript describes an exact test for answer changes beyond that floor. The test asks whether the item-level changes are larger than re-execution noise, rather than whether an average moved.

On the questions that were asked twice on both versions, mark two things: did the first answers of the two versions differ, and did a version’s first answer differ from its own second answer? Among the questions where those marks disagree, the exact conditional test asks whether between-version changes outnumber re-run disagreements by more than a fair coin would allow. The p-value is that exact chance. The effect is the change rate minus the larger re-run rate. The interval is an exact interval for that paired difference, given the questions where the two marks disagree.

Release gate

The release gate is an application of the item labels. It can stop a build when stable regressions exceed a limit you set. It is not the exact test, and it is not a certificate that a system is safe to deploy.

Labelled examples

The library question “How often must membership be renewed?” is item q02 in the synthetic demo. The drug question that names Zorvalin and Merdapine is item m01 in web/sample_medicines.csv. Those names, doses, and effects are invented illustration, not a study and not medical guidance. The browser tool labels that file “Invented drug names (illustration only)”.

What this software computes

ridi-check still reports the execution floor as a comparison of rounded rates. Beside it, the report now adds an exact conditional test. The label on that test is: implementation pending confirmation against the registered protocol. The rounded-rate comparison was not replaced. The arithmetic is written out in docs/STATISTICS.md.

For each version, the re-run rate is how often run 2 disagrees with run 1. Each rate is rounded to 6 decimal places. The floor is the larger of the two rates. The between-version change “exceeds the floor” only when its rate is strictly greater. Equal rates do not exceed it. A missing repeated run leaves the comparison undefined. Neither re-run rate is subtracted from the change. Wilson 95% intervals use z = 1.959964. They are not a hypothesis test, and the release gate does not use them.

Item labels are separate. “Stable” means every repeated run agreed with that version’s first run, and both versions were run at least twice. Otherwise the item is unstable, or unconfirmed when a version was run once.

The registered analysis script on osf.io/anbjd is a paired bootstrap: 20,000 within-benchmark draws, a control that is 1 when any of three same-context executions disagree, a margin of 2 percentage points, and a Holm adjustment across models. This package does not run that bootstrap. A results file here has two runs of each version and no benchmark column. That is why the conditional test is labelled pending confirmation.

Exploratory notes in this repository quote two exact binomial p-values (3 gains versus 5 losses, p = 0.7265625; 16 improvements versus 6 regressions, 13757/262144, which is 0.05248 to five decimal places). Those tests ask whether improvements and regressions are balanced. They are not the execution-floor test, and ridi-check report does not emit them.

المنهج بلغة مباشرة

يقدّم الأستاذ نور (جامعة الملك عبدالعزيز) هذه الحجة في مخطوطة. تصف هذه الصفحة المخطوطة بأنها قيد المراجعة. النسخة الأولية ستصدر لاحقاً.

بنود متطابقة

تجيب النسختان عن الأسئلة نفسها بمعرّفات الحالات نفسها. مقارنة تستخدم أسئلة مختلفة لكل نسخة لا تستطيع أن تقول أي الإجابات تحركت.

تشغيلات متكررة

تُشغَّل كل نسخة أكثر من مرة على هذه البنود المتطابقة. تشغيل واحد لا يفصل أثر التحديث عن إجابة كانت ستتغيّر من تلقاء نفسها.

أرضية التنفيذ

أرضية التنفيذ هي خط الأساس لضجيج إعادة التنفيذ: كم مرة تخالف النسخة نفسها نفسها. تُقرأ تغيّرات الإجابات مقابل هذه الأرضية. التغيير الذي يبقى داخل الضجيج ليس دليلاً على التحديث.

الاختبار الدقيق

تصف المخطوطة اختباراً دقيقاً لتغيّرات الإجابات التي تتجاوز هذه الأرضية. يسأل الاختبار إن كانت التغيّرات على مستوى البند أكبر من ضجيج إعادة التنفيذ، لا إن كان المتوسط قد تحرّك.

على الأسئلة التي طُرحت مرتين على كلتا النسختين، تُعلَّم علامتان: هل اختلفت إجابتَا التشغيل الأول بين النسختين، وهل اختلفت إجابة النسخة الأولى عن تشغيلها الثاني؟ بين الأسئلة التي تختلف فيها العلامتان، يسأل الاختبار الشرطي الدقيق إن كانت تغيّرات النسختين أكثر من اختلافات إعادة التشغيل بما يفوق عملة عادلة. قيمة p هي ذلك الاحتمال الدقيق. الأثر هو نسبة التغيّر ناقص أكبر نسبة إعادة تشغيل. الفترة دقيقة لهذا الفرق المزدوج، بشرط الأسئلة التي اختلفت علامتاها.

بوابة الإصدار

بوابة الإصدار تطبيق لتسميات البنود. يمكنها إيقاف البناء عندما تتجاوز التراجعات الثابتة حداً تضعه أنت. ليست الاختبار الدقيق، وليست شهادة بأن النظام آمن للنشر.

أمثلة موسومة

سؤال المكتبة «كم مرة يجب تجديد العضوية؟» هو البند q02 في المثال الاصطناعي. سؤال الدواء الذي يذكر Zorvalin وMerdapine هو البند m01 في web/sample_medicines.csv. الأسماء والجرعات والآثار توضيح مخترع، لا دراسة ولا إرشاد طبي. تعلّم أداة المتصفح الملف بعبارة Invented drug names (illustration only).

ما يحسبه هذا البرنامج

ما زال ridi-check يعرض أرضية التنفيذ كمقارنة لنسب مُقرَّبة. وإلى جانبها يضيف التقرير اختباراً شرطياً دقيقاً. التسمية على هذا الاختبار: التنفيذ بانتظار التأكيد مقابل البروتوكول المسجّل. لم تُستبدل مقارنة النسب المُقرَّبة. الحسابات مكتوبة في docs/STATISTICS.md.

لكل نسخة، نسبة إعادة التشغيل هي كم مرة يختلف التشغيل الثاني عن الأول. تُقرَّب كل نسبة إلى 6 منازل عشرية. الأرضية هي أكبر النسبتين. «تجاوز التغيير للأرضية» لا يقع إلا إذا كانت نسبته أكبر بصرامة. النسب المتساوية لا تتجاوزها. غياب تشغيل متكرر يجعل المقارنة غير معرّفة. لا تُطرح أي نسبة إعادة تشغيل من التغيير. فترات Wilson بنسبة 95% تستخدم z = 1.959964. ليست اختبار فرضية، وبوابة الإصدار لا تستخدمها.

تسميات البنود مستقلة. «ثابت» يعني أن كل تشغيل متكرر وافق التشغيل الأول لتلك النسخة، وأن النسختين شُغّلتا مرتين على الأقل. وإلا فالبند غير مستقر، أو غير مؤكَّد إذا شُغّلت نسخة مرة واحدة.

نص التحليل المسجّل على osf.io/anbjd إعادة معاينة مزدوجة: 20,000 سحبة داخل كل معيار، وضابط يساوي 1 إذا اختلف أي تنفيذ من ثلاثة تنفيذات للسياق نفسه، وهامش نقطتين مئويتين، وتصحيح Holm عبر النماذج. لا يشغّل هذا البرنامج تلك الإعادة. ملف النتائج هنا فيه تشغيلان لكل نسخة ولا عمود للمعيار. لذلك يُعلَّم الاختبار الشرطي بأنه بانتظار التأكيد.

تذكر ملاحظات استكشافية قيمتي p ذات حدّين دقيقتين (3 مكاسب مقابل 5 خسائر، p = 0.7265625؛ و16 تحسيناً مقابل 6 تراجعات، 13757/262144، أي 0.05248 عند خمس منازل). يسأل هذان الاختباران إن كانت التحسينات والتراجعات متوازنة. ليسا اختبار أرضية التنفيذ، ولا يُخرجهما ridi-check report.

Commercial replication / التكرار التجاري

Preregistered commercial replication: criterion H1c, support in at least 2 of 3 models after Holm, was not met. Gemini 3.8 Flash +0.0347 [0.0247, 0.0452] was supported. GPT-5.4 mini +0.0098 [-0.0024, 0.0221] and Claude Sonnet 5.5 +0.0074 [-0.0023, 0.0174] were not. The same reported differences were previously written here as percentage points: Gemini 3.8 Flash +3.47 points [2.47, 4.52], GPT-5.4 mini +0.98 [-0.24, 2.21], and Claude Sonnet 5.5 +0.74 [-0.23, 1.74]. +3.47 points is +0.0347. The magnitude is model-dependent and has to be measured for each model.

Reporting a registered criterion that did not hold is part of the registration. The partial support for one model is not rounded up into a general effect. These figures are the reported result. They were not recomputed from files in this repository.

Comparison

The table says what each tool is for. It is not a ranking. This repository has not run the other tools on the same items and does not invent scores for them. What RIDI adds is a report of item-level transitions beyond a re-execution floor. That is not a claim of superiority. The same table is in docs/COMPARISON.md.

يقول الجدول وظيفة كل أداة. ليس ترتيباً. لم تُشغَّل الأدوات الأخرى على البنود نفسها في هذا المستودع، ولا تُخترع لها درجات. ما تضيفه RIDI تقرير بانتقالات على مستوى البند تتجاوز أرضية إعادة التنفيذ. هذا ليس ادّعاء تفوّق. خلايا الجدول بالإنجليزية حتى تبقى أسماء الأدوات كما هي. الجدول نفسه في docs/COMPARISON.md.

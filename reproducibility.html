Reproducibility

Everything below is copied from files in this repository. The commercial replication is not among them, so those model runs cannot be rebuilt from this page. The same note is in docs/REPRODUCIBILITY.md.

Package

Runtime dependencies: none. Python 3.10 or later. The test workflow uses Python 3.10, 3.13, and 3.14 on Ubuntu, Windows, and macOS.

pip install ".[test]" anthropic
pytest -q

On Ubuntu with Python 3.13 the workflow also runs pytest -q --cov=ridi_check --cov-branch --cov-fail-under=95. Test packages are pinned only as pytest>=7 and pytest-cov>=4. There is no lockfile of transitive test packages.

Offline demo

The toy assistant seeds tie-breaks with SEED = 7. The current version does not use that generator. Questions are the constructed library handbook. Each version runs twice. Data are synthetic.

pip install ridi-check
ridi-check demo

إعادة الإنتاج

كل ما يلي منقول من ملفات هذا المستودع. التكرار التجاري ليس بينها، فلا تُعاد بناء تلك التشغيلات من هذه الصفحة. الملاحظة نفسها في docs/REPRODUCIBILITY.md.

الحزمة

لا اعتمادات وقت تشغيل. Python 3.10 أو أحدث. يستخدم سير الاختبار إصدارات Python 3.10 و3.13 و3.14 على Ubuntu وWindows وmacOS.

pip install ".[test]" anthropic
pytest -q

على Ubuntu مع Python 3.13 يشغّل السير أيضاً pytest -q --cov=ridi_check --cov-branch --cov-fail-under=95. أدوات الاختبار مقيّدة فقط بـ pytest>=7 وpytest-cov>=4. لا يوجد ملف قفل للاعتمادات العابرة.

التشغيل التجريبي دون شبكة

يبذر المساعد الاصطناعي كسر التعادل بـ SEED = 7. النسخة الحالية لا تستخدم ذلك المولّد. الأسئلة دليل مكتبة مبني. كل نسخة تُشغَّل مرتين. البيانات اصطناعية.

pip install ridi-check
ridi-check demo
